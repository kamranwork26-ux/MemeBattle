// About

MemeBattle is a meme ranking experiment where two random memes go head to head and you decide which one is superior. Every vote updates each meme's ELO rating — the same algorithm used to rank chess players worldwide.

Memes are pulled live from Reddit so the pool is always fresh, always random, and honestly sometimes cursed. The leaderboard is shared across all users in real time — every vote from every visitor counts.

Built as a first web project to learn HTML, CSS and JavaScript from scratch. No frameworks, no shortcuts — just vanilla code and a lot of debugging.
